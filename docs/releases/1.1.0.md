# GamePile 1.1.0

GamePile 1.1.0 adds backup restore, editable taste learning, and reversible
backlog decisions, with fixes for saves and library refreshes.

## What's new

- **Restore your backups.** Import backups from 1.0 or 1.1, preview changes,
  choose how conflicts are handled, and keep an automatic recovery export.
- **Taste learning you can edit.** Personal ratings now teach recommendations.
  Changing or clearing a rating replaces its contribution; repeated feedback
  submissions no longer count twice.
- **Undo and resume.** Undo quick decisions, restore excluded games, clear
  technical issue flags, and resume Decision Sessions after visiting details.
- **Temporary skips.** “Not feeling it” skips a game for the current round.
  Find Games / Reset clears those skips without affecting taste or exclusions.
- **Clearer HLTB matches.** See the matched title, source record, match method,
  and last successful fetch.

## Fixes

- Shortlist picks, notes, manual hours, ratings, and partial feedback save
  reliably, including repeated edits.
- Refreshes preserve manual changes made while a fetch is running.
- Steam, HLTB, tags, and achievement updates handle their refresh timing
  independently. Incomplete Steam responses no longer remove library ownership.
- HTMX ships with the app; core interactions no longer need a CDN connection.
- Local write requests are protected against cross-site requests, and failed
  requests show useful errors.

## Upgrading from 1.0

Export a backup in Settings before upgrading. The first launch migrates the
database automatically and preserves existing data and learned taste.

Older completed feedback remains visible but cannot have its original taste
contribution edited: 1.0 did not record enough history to reverse it precisely.
Use a personal rating for new feedback on those games.

Backup restore merges data. It preserves records that exist only locally, so
reimporting a recovery export is not an exact rollback. Missing games are
restored as inactive placeholders; refresh Steam afterward to rebuild fetched
metadata and establish current ownership. Credentials are not in backups.

## Validation

All 17 regression suites passed locally, including 23 workflow tests.
Manual Windows and CachyOS install, launch, upgrade, and uninstall checks have
not been completed for this version. The existing release workflow builds a
Windows installer and Linux AppImage and initially marks releases as prereleases
pending those checks.
